> **LoyalLens AI** is an enterprise-grade, hackathon-winning platform that transforms passive e-commerce analytics into an **autonomous customer retention engine**. By combining real-time behavioral signal ingestion, SHAP-driven explainable AI (XAI), dynamic offer generation, and automated omnichannel execution, LoyalLens AI predicts churn before it occurs and recovers revenue automatically.

---

## ✨ Key Features & WOW Factor

### 📡 1. Real-Time Churn Radar & Telemetry Stream
- Continuous ingestion of webhooks (cart abandonment, shipping delays, negative ticket sentiment, login velocity drops).
- Dynamic risk tier categorization (**High >70%**, **Medium 35-70%**, **Low <35%**).

### 🔍 2. SHAP Explainable AI (XAI) Customer 360
- Eliminates "black-box ML" by displaying exact feature impact weights per customer (e.g. `+38% Risk due to 3 consecutive shipping delays`).
- Interactive customer timeline mapping behavioral friction events.

### 🤖 3. Autonomous AI Retention Studio
- LLM agent generates hyper-personalized retention bundles (custom incentives, tailored microcopy, and dynamic promo codes).
- Omnichannel live preview tabs: **Email**, **WhatsApp Business API**, **SMS**, and **Synthetic Voice Strategy Brief**.

### 📈 4. "What-If" ROI Revenue Recovery Simulator
- Interactive parameter sliders (Budget, Target Risk Tier, Discount %, Conversion Boost).
- Live 6-month projected revenue recovery graph comparing unmitigated churn vs. LoyalLens recovery.

### 🎤 5. Integrated 2-Minute Judge Pitch Deck Mode
- Built-in slide deck reader with presentation controls, bulletproof judge Q&A defense, and 1-click demo shortcuts.

## ⚡ Quick Start & Installation

```bash
# 1. Clone repository
git clone https://github.com/your-username/loyal-lens-ai.git
cd loyal-lens-ai

# 2. Install dependencies
npm install

# 3. Launch local dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
